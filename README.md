# assets/

Add your official Dezyd logo files here (they are not included because the brand
guidelines forbid redrawing or altering the logo):

| File | Used for |
|------|----------|
| `dezyd-logo-white.svg` | Textual logo, white version (shown on the black header) |
| `dezyd-icon.svg` | Logo icon (D lettermark), used as the browser-tab favicon |

Until the logo file exists, the header simply hides the logo slot.
